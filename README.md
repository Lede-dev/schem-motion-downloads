# Schem Motion 다운로드

Windows x64용 Schem Motion 실행 파일을 제공합니다. 이 저장소에는 배포 안내와 실행 파일만 있으며 앱 소스 코드는 포함하지 않습니다.

[최신 버전 다운로드](https://github.com/Lede-dev/schem-motion-downloads/releases/latest)

ZIP 파일을 내려받아 폴더 전체를 압축 해제하고 `SchemMotion.exe`를 실행하세요. Minecraft 텍스처·폰트·설치음과 동영상 인코더가 포함되어 있습니다. 별도 게임 설치 없이 미리보기와 MP4 내보내기를 사용할 수 있습니다.

더 작은 파일은 7z 형식으로 제공합니다. 7z 파일은 7-Zip 등 지원 프로그램으로 압축을 풀어주세요. 두 압축 파일의 구성은 동일합니다.

회사 내부 사용을 위한 도구입니다. 포함된 구성 요소의 출처와 라이선스는 압축 파일 안의 고지 문서를 참고하세요.
